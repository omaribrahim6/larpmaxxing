# Specification and current scope
The complete original v1.1 design is preserved in SPEC-v1.1.html, recovered from Claude's local artifact scratchpad (last edited September 11, 2026 around 01:40 Toronto).
The subsequent explicit user instruction at 01:43 narrows implementation to a vertical prototype: Bag only, modular trend framework, autonomous Studio integration and playtests. No monetization, global leaderboards, rebirth, events, VIP/Elite areas or other four stats yet. This supersedes the broader MVP phase listed in the design.
Loop: collect Bag props -> stats/rank -> challenge -> Bag skit -> server-calculated rewards. Losing removes no points.
Ranks: NPC 0; Normie 250; Wannabe 1500; Poser 6000; Main Character 20000; Aura Farmer 60000; LARP Maxxer 150000.
Challenge: 12 studs, 10-second response timeout, 30-second same-target decline cooldown. Rematch window 60 seconds in current Tuning.
Player UI: config-driven rank/progress, stat values, wins, accept/decline, settings, notices, stamps and rematch. No invented event content.
Persistent settings currently accepted by Claude's service: acceptLarpOffs, clipMode, reduceEffects (booleans). Additional UI preferences must not be presented as saved until persistence exists.
NPCs fictional, gender-neutral content, cartoonish fumbles, no appearance ratings or branded assets. See full artifact for exact formulas, timings and scene sheets.
