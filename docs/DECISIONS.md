- 2026-09-14 (Claude): Drivable cars use Roblox constraints, per the physics docs: an invisible chassis carries the mass; each wheel hangs on a knuckle from a CylindricalConstraint (vertical sliding = suspension travel within limits; rotation about the same axis = a steering servo, held straight on the rear) with a SpringConstraint for spring and damper; a HingeConstraint motor spins it. CarRig works the strengths out from the car's mass so Config.Cars stays in studs and seconds. The driver's client owns the physics and sets the motors (LarpClient.Drive). This game has no PlayerModule, so Drive reads the keys, gamepad and MoveDirection itself when the seat's throttle is 0, and starts on SeatPart (Humanoid.Seated can miss a server-side Sit).
- 2026-09-14 (Claude): Tripo cars that drive must arrive as a body plus four separate wheel meshes (Tripo mesh_segmentation, then an FBX with one mesh per part), since CarRig turns the named wheel parts into physics wheels.
